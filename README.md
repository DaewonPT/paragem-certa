# Paragem Certa

App Android gratuita de transportes públicos para Portugal: chegadas em tempo real, rotas, as linhas dos operadores da Área de Lisboa, um widget com as próximas chegadas e um aviso para saíres na paragem certa. Sem anúncios nem subscrições.

A conta, a comunidade (relatos, fotos e correções) e os autocarros da Carris ao vivo só aparecem quando estão ligados no servidor: ver `docs/servidor.md`.
