# Paragem Certa

App Android gratuita de transportes públicos para Portugal: chegadas em tempo real, rotas e um aviso para saíres na paragem certa. Sem anúncios nem subscrições.

Feita pela **Pixel Lusitano** (Alize.On.Me). Código sob a licença GPL-3.0; o nome e o logótipo "Paragem Certa" não estão incluídos na licença.
